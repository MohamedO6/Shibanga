# Undula submission media

Static PNG figures for the NASA project editor, paired with the complete original GIFs.

The PNG figures are composed from existing application captures and cited observations. Original source images and GIFs are unchanged.

Astrounit character: Google Flow (AI-generated). Its visible disclosure is retained. NASA catalogue previews are unchanged.

Model outputs, observations, and Sea 2100 assumptions are labelled separately in the figures. Model sonification GIFs are silent.
